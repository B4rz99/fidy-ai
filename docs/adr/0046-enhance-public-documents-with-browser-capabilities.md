# Keep public documents usable across browser capabilities

A docs theme selection applies to the current page even if the browser refuses durable preference
storage. The sidebar allows one CSS pixel for rounding when native anchor scrolling determines the
active heading. Exact coordinates can otherwise highlight the preceding section after a valid
fragment navigation.

Use animation longhands for the landing page's named scroll timeline. The CSS optimizer otherwise
combines the declarations into a shorthand that can replace the intended timeline. The named
timeline stays inside the capability and reduced-motion gates.

The product theme similarly uses the system preference when durable storage is unavailable.
