# Production provider inventory

| Provider     | Purpose and data boundary                                                                                                                                                              | Operational/legal check                                                                                                                                                                                            |
| ------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Cloudflare   | Public/Core Workers, static web, D1, per-User Durable Objects, Queues, Workflows, private R2, Email Workers and Workers AI. | Kapso / Meta | WhatsApp delivery and inbound messages; Kapso-generated voice transcripts can use additional subprocessors. Free-plan history is not automatically deleted. |
| Wompi        | Browser card tokenization and verified Subscription billing; Fidy does not store card details.                                                                                         | Reconcile ambiguous BillingAttempts against verified evidence; see [billing ambiguity](../runbooks/billing-ambiguity.md).                                                                                          |
| Resend       | Outbound authentication, recovery and service email only.                                                                                                                              | No Resend Receiving, Svix webhook or inbound mailbox; forwarded mail enters through Cloudflare Email Workers when sender and Connection admission are available.                                                   |

This is an operator inventory, not a substitute for the User-facing [privacy policy](../../apps/web/src/features/public-site/legal/policy.html) or the immutable [onboarding disclosure](../../apps/server/src/shell/consent/current-disclosure.ts). Any material public-copy change requires a new revision and digest; verify contracts and actual provider settings before enabling a new purpose.
