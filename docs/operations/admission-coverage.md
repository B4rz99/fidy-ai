# Admission and spend coverage (#715)

Resource admission is not a commercial Free allowance. The private Core Worker owns D1 authority;
per-User Durable Objects serialize coordinated work but do not hold counters. Public ingress and
Cloudflare edge limits only shed cheap traffic. Store failures return unavailable, not quota
exhaustion. A source key before User resolution is never a substitute for a stable User after
resolution. Limits below describe current installed controls, not new product entitlements.

**Remaining equivalence evidence before closing #715:** a dedicated durable Workers AI spend
reservation shared by hosted Turns and Memory inference is not yet installed. Bounded per-Turn
rounds and per-request tokens are not a _cross-Turn_ spend ceiling. Rejected attempts outside the
statement-upload boundary are also not uniformly counted by a separate pressure budget; existing
proof/source rate controls vary by surface. Neither gap should be described as covered by the
shared D1 primitive just because its policy dimension exists. Preserve the existing semantics until
those paths have public-seam negative tests and a reviewed per-class cost unit. Commercial Free
allowances from #35 remain out of scope.
