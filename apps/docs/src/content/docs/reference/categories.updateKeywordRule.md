Referencia generada. Consulta las [guías](/) para explicaciones y ejemplos en español.

Replace one of the caller's keyword instructions for future capture. Existing Transaction Categories remain unchanged.

## Acceso

Permiso: **write**.

Plan requerido: **free**. Tipo: **mutation**.

Confirmación sensible: **required**.

## Interfaces

- MCP: herramienta `categories.updateKeywordRule`; los argumentos exactos se descubren en tu cliente según tus permisos.
- CLI: `fidy categories updateKeywordRule --help`.
- API: `PUT https://api.fidyapp.com/category-keyword-rules/{id}`.
