Get the stable User behind the authenticated bearer and the independently stored ServiceMarket, locale, and IANA time zone. Use it before interpreting dates or presenting data to the User.

## Acceso

Permiso: **read**.

Plan requerido: **free**. Tipo: **query**.

Confirmación sensible: **not-required**.

## Interfaces

- MCP: herramienta `identity.getCurrentUser`; los argumentos exactos se descubren en tu cliente según tus permisos.
- CLI: `fidy identity getCurrentUser --help`.
- API: `GET https://api.fidyapp.com/user`.

## Parámetros HTTP

```json
[]
```

## Cuerpo HTTP

Esta operación no declara cuerpo HTTP.
