## Proof sequence

1. Run the existing release/artifact, topology, private-Core and edge gates. The expanded
   `verify-edge-smoke.ts` probes discovery, the exact unauthenticated challenge, malformed
   registration/token/authorization, missing browser Origin and hostile MCP Origin. It checks
   no-store/referrer/CSP headers, no permissive CORS and no interactive edge challenge. Candidate
   runs must return the exact public Worker version even on GET requests. Status/header probes do
   not establish metadata-body correctness, client interoperability or WAF/rate enforcement.
2. For each exact supported Claude Code/Codex version, add the hosted URL in an isolated profile.
   Complete established Fidy sign-in, remove a requested permission, choose a bounded duration,
   review expiration and approve. Record the actual registration mechanism; CIMD remains unavailable
   in the installed authority, and historical CIMD simulator evidence does not prove DCR fallback.
   Do not bypass registration with a manually injected bearer and label it a login proof.
3. Observe private tools/list and a query, one ordinary mutation and an atomic batch through the
   existing canonical owners. Review a sensitive action in the native form; cancel once and accept
   once. Verify the exact resulting state and attributable metadata-only Audit through approved
   interfaces. The form asserts authorized-client acceptance, not independent human presence.
4. Reconnect in a new host process and observe refresh without extending the approved expiration.
   Exercise expiry only under the approved clock/fault procedure; never rewrite Production grant
   rows ad hoc. Revoke from fresh first-party settings and prove later calls and refresh fail.
   Verify logout/PAT controls remain independent. A new browser approval creates a new connection.
5. Exercise only approved bounded interruption/pressure scenarios. Lost mutation delivery requires
   observing the retained result, never blind replay. Preserve original retry identity for decoded
   non-admission pacing. Confirm metadata-only telemetry for success, refusal and interruption.
   Local streaming/coordination tests do not prove Cloudflare platform suspension or account limits.
6. Reconcile synthetic effects and drain work through owning lifecycles before purpose-bound
   cleanup. Observe cleanup across the relevant expiry/retry window and retain migration hashes,
   Category seeds and the authoritative baseline. Code traffic rollback does not roll back state.
