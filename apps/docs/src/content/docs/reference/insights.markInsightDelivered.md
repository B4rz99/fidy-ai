Record one actual external send attempt for the caller's pending InsightEvent and mark it delivered. Use this only after a provider accepted the send: supply its UTC send instant, channel, provider, and message id. This operation sends nothing itself.

## Acceso

Permiso: **write**.

Plan requerido: **free**. Tipo: **mutation**.

Confirmación sensible: **required**.

## Interfaces

- MCP: herramienta `insights.markInsightDelivered`; los argumentos exactos se descubren en tu cliente según tus permisos.
- CLI: `fidy insights markInsightDelivered --help`.
- API: `POST https://api.fidyapp.com/insights/{id}/delivered`.
