Create or reuse your stable Connection and a ten-minute browser authorization attempt. Reuse a live attempt; an Active Connection returns already connected. This operation grants no institution authority.

## Acceso

Permiso: **write**.

Plan requerido: **free**. Tipo: **mutation**.

Confirmación sensible: **not-required**.

## Interfaces

- MCP: herramienta `connections.connectInstitution`; los argumentos exactos se descubren en tu cliente según tus permisos.
- CLI: `fidy connections connectInstitution --help`.
- API: `POST https://api.fidyapp.com/connections`.
