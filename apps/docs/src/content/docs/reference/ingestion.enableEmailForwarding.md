Referencia generada. Consulta las [guías](/) para explicaciones y ejemplos en español.

Idempotently enable one permanent unpredictable forwarding address for the caller. Later calls return the same address.

## Acceso

Permiso: **write**.

Plan requerido: **free**. Tipo: **mutation**.

Confirmación sensible: **not-required**.

## Interfaces

- MCP: herramienta `ingestion.enableEmailForwarding`; los argumentos exactos se descubren en tu cliente según tus permisos.
- CLI: `fidy ingestion enableEmailForwarding --help`.
- API: `POST https://api.fidyapp.com/ingestion/email-forwarding`.

## Parámetros HTTP

```json
[]
```

## Cuerpo HTTP

Esta operación no declara cuerpo HTTP.
