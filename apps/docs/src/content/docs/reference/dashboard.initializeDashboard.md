Initialize your default four-Widget DashboardDocument before using it. If one already exists, return it unchanged, preserving all edits; repeated calls never reset your Dashboard.

## Acceso

Permiso: **dashboard**.

Plan requerido: **free**. Tipo: **mutation**.

Confirmación sensible: **not-required**.

## Interfaces

- MCP: herramienta `dashboard.initializeDashboard`; los argumentos exactos se descubren en tu cliente según tus permisos.
- CLI: `fidy dashboard initializeDashboard --help`.
- API: `POST https://api.fidyapp.com/dashboard/initialize`.

## Parámetros HTTP

```json
[]
```

## Cuerpo HTTP

Esta operación no declara cuerpo HTTP.
