Revise your existing reminder cadence, local time and IANA zone with the version you read. A stale version is refused: read again before retrying. This does not activate reminders, change delivery Consent, or rewrite historical occurrences.

## Acceso

Permiso: **write**.

Plan requerido: **free**. Tipo: **mutation**.

Confirmación sensible: **required**.

## Interfaces

- MCP: herramienta `insights.updateReminderSchedule`; los argumentos exactos se descubren en tu cliente según tus permisos.
- CLI: `fidy insights updateReminderSchedule --help`.
- API: `POST https://api.fidyapp.com/insights/reminder`.
