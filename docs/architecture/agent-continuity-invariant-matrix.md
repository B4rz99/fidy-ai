# Issue #11 invariant matrix

Status: **accepted implementation contract**  
Decision: [ADR 0014](../adr/0014-deep-hosted-turn-modules.md)  
The untracked research under `reports/issue-11/` was decision input only. It is neither linked nor incorporated as a proposed public interface; ADR 0014 and this matrix are the complete accepted contract.

This matrix is the pre-implementation contract. Each row names the owning module, the confirmed public test seam, an executable assertion, and the implementation ticket that must make it green. Implementation proceeds vertically: select one row, add the named failing test at that seam, make only that row green, then continue. Do not create tests against private selection loops, SQL fragments, prompt-array helpers, or tokenizer internals.

## Execution gate

A row is complete only when its assertion runs at the named seam and fails if the invariant is deliberately violated. `todo`, skipped, snapshot-only, interaction-only, and tautological tests do not satisfy the row. The redesign is complete only when every row is green under:

```sh
bun run format
bun run lint
bun run lint:type-aware
bun run lint:deps
bun run typecheck
bun run check:continuity-invariants
bun run test
```

`check:continuity-invariants` fails unless every accepted row maps exactly once to concrete,
non-skipped executable test declarations; one row may cite several declarations when its assertion
spans accepted seams. It also inventories every production `Config.redacted` credential and requires
focused evidence for each adapter path, so adding an invariant row or credential cannot silently
bypass the release gate. The tests themselves remain in their ordinary unit, integration, and
acceptance suites; the check proves completeness without creating a second execution path.

Real-Postgres rows run through the existing API, agent, or repository integration harness. Hosted-provider rows use the production `HostedInference` interface with a deterministic adapter; they do not mock internal collaborators.

## Migration discipline

- The confirmed external seams are `HostedInference`, `WorkingContext`, `ConversationContinuity`, the canonical Memory operations, the existing API seam, agent seam, channel-worker seam, and public-channel acceptance seam.
- Postgres is local-substitutable and remains behind ConversationContinuity; do not expose a repository port merely to mock it.
- OpenAI is truly external, so HostedInference has production and deterministic adapters.
- Replace shallow tests when the corresponding interface row is green. Do not layer new tests on both old helpers and the deep module.
- This matrix, ADR 0014, the issue body, and the tracked `ARCHITECTURE.md` summary must remain aligned on terminology and sequencing. Historical research sketches are not contract documents.
