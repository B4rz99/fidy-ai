Read one owned ingestion item and its revision-bound draft. Expired drafts are not disclosed; the original deadline never extends.

## Acceso

Permiso: **read**.

Plan requerido: **free**. Tipo: **query**.

Confirmación sensible: **not-required**.

## Interfaces

- MCP: herramienta `ingestion.getReviewItem`; los argumentos exactos se descubren en tu cliente según tus permisos.
- CLI: `fidy ingestion getReviewItem --help`.
- API: `GET https://api.fidyapp.com/ingestion/review-workspace/{id}`.

## Parámetros HTTP

```json
[
```

Esta operación no declara cuerpo HTTP.
