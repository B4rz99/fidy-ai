List your Connections and their product lifecycle states.

## Acceso

Permiso: **read**.

Plan requerido: **free**. Tipo: **query**.

Confirmación sensible: **not-required**.

## Interfaces

- MCP: herramienta `connections.listConnections`; los argumentos exactos se descubren en tu cliente según tus permisos.
- CLI: `fidy connections listConnections --help`.
- API: `GET https://api.fidyapp.com/connections`.

## Parámetros HTTP

```json
[]
```

## Cuerpo HTTP

Esta operación no declara cuerpo HTTP.
