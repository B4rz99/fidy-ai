Permanently delete one Budget and its operational monthly alert marks.

## Acceso

Permiso: **write**.

Plan requerido: **free**. Tipo: **mutation**.

Confirmación sensible: **required**.

## Interfaces

- MCP: herramienta `budgets.deleteBudget`; los argumentos exactos se descubren en tu cliente según tus permisos.
- CLI: `fidy budgets deleteBudget --help`.
- API: `DELETE https://api.fidyapp.com/budgets/{id}`.

## Parámetros HTTP

```json
[
  {
    "in": "path",
    "name": "id",
    "required": true,
    "schema": {
      "$ref": "#/components/schemas/BudgetId"
    }
  }
]
```

## Cuerpo HTTP

Esta operación no declara cuerpo HTTP.
