# MCP implementation evidence — #1260

Assessment date: 2026-10-13. Baseline: merged #1259, `01a63f1c414b1877a9abd6c68d8b8de2fb840af6`.
This assesses Fidy's server-owned MCP resource, OAuth lifecycle and canonical-operation
boundary. It is not certification, an exhaustive penetration test, or verification of an
external agent client's behavior. The [reference inventory](owasp-reference-verification-2026-10-13.md)
pins the **MCP Top 10 2025 beta** category names; its beta status is retained.

`Verified scoped` means the stated control has implementation and behavioral evidence;
it does not mean the entire OWASP category is solved. `Partial` means an identified
sub-boundary remains outside that evidence. `Accepted` names an intentional trust limit.
Tests below use local published Worker/Core/Miniflare/D1 boundaries, not production.
Paths are repository-relative. OAuth test names refer to files under
`apps/server/cloudflare/oauth-agents/` unless a full path is given.

## Resource and residency evidence

The beta category titles do not separately enumerate every resource-consumption failure.
`apps/server/cloudflare/mcp/runtime.ts` bounds request/response bytes, canonical execution,
transport lifetime, eight resident owners, and a five-minute absolute resident lifetime.
Disposal retains capacity until native cleanup/started work settles; credential or grant
expiry can retire a subscription without waiting for client disconnect.

`oauth-native-residency.test.ts` directly exercises:

- **native residency bounds eight unread response owners and preserves stock repeated and batched initialize rejection**.
- **reclaims eight native subscriptions after %s without client disconnect** for expiry,
  revocation and maximum lifetime; verifies previously held capacity becomes usable.
- **native residency counts a retiring started atomic owner until SQL and streaming disposal finish**.
- **native residency essential actual SDK disposal waits for public Scope cleanup before replacement capacity**.
- **native residency running and queued cancellation controls do not release predecessor or native SQL settlement**.

This proves the tested local lifecycle, not global deployed capacity or an external client's
consumption limits. Shared canonical stable-User allowance evidence is recorded with the
API assessment; issuing another grant does not create a separate financial execution owner.

## Execution record

The targeted command runs from `apps/server` with one worker and no file parallelism:

```sh
bun run test:cloudflare cloudflare/oauth-agents/oauth-expiry.test.ts cloudflare/oauth-agents/oauth-refresh.test.ts cloudflare/oauth-agents/oauth-confirmation.test.ts cloudflare/oauth-agents/oauth-discovery.test.ts cloudflare/oauth-agents/oauth-native-residency.test.ts cloudflare/oauth-agents/oauth-management.test.ts cloudflare/public-worker-mcp.test.ts --maxWorkers=1 --no-file-parallelism
```

Results:

- First seven-file run: **129 passed, 4 failed, 1 skipped**, 161.75 seconds. All six
  non-confirmation files passed. Confirmation failures were the two **rechecks live
  authority while consuming native evidence in the protected %s unit** cases and the
  two **does not lend native intent authority to another connection of User %s** cases.
  Two hit the 15-second test deadline; two failed fixture decoding after slow request
  setup returned an unavailable envelope instead of successful creation.
- Confirmation-only rerun, unchanged command flags and deadlines: **23 passed,
  1 failed, 1 skipped**, 53.75 seconds. All four initial failures passed. The different
  **refuses decline and cancellation without deletion or acceptance and fences each
  refused intent** case hit the 15-second test deadline.
- That last case alone with `-t 'refuses decline and cancellation'`: **1 passed,
  24 filtered/skipped**, 4.50 seconds. Logs: `/tmp/fidy-mcp-confirmation-1260.log`
  and `/tmp/fidy-mcp-confirmation-focused-1260.log` (local, non-portable artifacts).

All **133 executable cases passed at least once across these sequential runs**; there
was **no single clean aggregate run**. The deliberate optional skip is **serves the real
confirmation seam to pinned native hosts**, which requires its native host bridge.
Consequently this run does not establish native-host integration or production behavior.
Observed multi-second fixture requests and unrelated host CPU contention support a timing
explanation for the inconsistent failures, but do not prove it. Preserve the failed-run
record and require CI confirmation rather than weakening production or test deadlines.

Existing #1259 CI is baseline evidence only, never presented as a newly executed result.
No new production code flaw was demonstrated by the bounded source inspection; no production
configuration or effect was changed. Native-client human-presence trust remains accepted
under ADR 0033. The matrix's scoped assertions refer to the named tested behaviors and must
be read with these execution limits.
