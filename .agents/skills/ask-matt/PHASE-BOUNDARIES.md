# Session transitions

Continue in the current session while its context is useful. Use a handoff when work moves to another session, harness, repository, or person. Preserve the objective, settled decisions and their reasons, current state, verification evidence, and remaining work.

Compaction depends on the host and available context, not a universal token threshold. A phase boundary is a convenient time to summarize, but a required mid-task compaction does not end the task. Resume from the recorded state.

Delegate a bounded subtask only when the user or active workflow calls for it. If that workflow requires Herdr, use its documented isolation and environment checks. A session transition alone is not a reason to spawn workers.
