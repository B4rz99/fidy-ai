Referencia generada. Consulta las [guías](/) para explicaciones y ejemplos en español.

Update the User's editable presentation locale and named IANA time zone. Use it when the User asks to change either preference; ServiceMarket cannot be changed here.

## Acceso

Permiso: **write**.

Plan requerido: **free**. Tipo: **mutation**.

Confirmación sensible: **not-required**.

## Interfaces

- MCP: herramienta `identity.updateUserPreferences`; los argumentos exactos se descubren en tu cliente según tus permisos.
- CLI: `fidy identity updateUserPreferences --help`.
- API: `PATCH https://api.fidyapp.com/user/preferences`.
