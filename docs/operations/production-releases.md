# Production releases

The **Release native application** workflow runs from protected `trunk` in the GitHub `production` environment. Application deployment requires an explicit dispatch. The workflow serializes writes under `production-deployment`. Pull requests run the repository gates, build the production assets and exercise the native adapters. Merging a prerequisite leaves ordinary application admission closed. The CLI and customer documentation have independent publication workflows.
