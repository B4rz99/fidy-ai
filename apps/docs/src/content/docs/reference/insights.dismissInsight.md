Dismiss one pending, delivered, or read InsightEvent of the caller. Use this when the occurrence should receive no further attention; dismissed events cannot move again.

## Acceso

Permiso: **write**.

Plan requerido: **free**. Tipo: **mutation**.

Confirmación sensible: **required**.

## Interfaces

- MCP: herramienta `insights.dismissInsight`; los argumentos exactos se descubren en tu cliente según tus permisos.
- CLI: `fidy insights dismissInsight --help`.
- API: `POST https://api.fidyapp.com/insights/{id}/dismissed`.

## Parámetros HTTP

```json
[
  {
    "in": "path",
    "name": "id",
    "required": true,
    "schema": {
      "$ref": "#/components/schemas/InsightEventId"
    }
  }
]
```

## Cuerpo HTTP

Esta operación no declara cuerpo HTTP.
