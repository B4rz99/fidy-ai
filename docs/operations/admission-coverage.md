# Admission and spend coverage (#715)

Resource admission is not a commercial Free allowance. The private Core Worker owns D1 authority;
per-User Durable Objects serialize coordinated work but do not hold counters. Public ingress and
Cloudflare edge limits only shed cheap traffic. Store failures return unavailable, not quota
exhaustion. A source key before User resolution is never a substitute for a stable User after
resolution. Limits below describe current installed controls, not new product entitlements.

Workers AI, PaymentEnrollment preparation) are separately bounded. Cheap canonical audit-budget and

are discarded without assigning a stable User. Proof/source controls before User creation follow
their own bounded rules. Commercial Free allowances from #35 remain out of scope.
